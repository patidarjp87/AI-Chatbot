OUTPUT FORMAT
Return ONLY valid JSON. No markdown, no code fences, no commentary.
Use exactly this shape:

{
  "title": "string",
  "slug": "string",
  "description": "string",
  "hashtags": ["#Shorts", "#DigitalSamajh"],
  "layout": "default",
  "scenes": [
    {
      "text": "string",
      "keyword": "string",
      "on_screen_text": "string",
      "highlight_words": ["string"],
      "presenter_moment": false
    }
  ]
}

RULES FOR EACH FIELD
- title: Hindi (Devanagari), at most 70 characters, specific and honest. Create curiosity without fake alarm. No hashtags.
- slug: 2 to 5 English words in lowercase joined by hyphens, naming the topic (used for a file name), for example "otp-fraud-basics".
- description: Hindi. Two or three natural sentences about what viewers will learn, then a blank line, then one line starting with "Sources:" followed by the source names from the source material exactly as given. Never invent sources or web addresses.
- hashtags: 4 to 6. Always include #Shorts and #DigitalSamajh. The others can be Hindi or English topic hashtags.
- layout: choose one of: <<LAYOUTS>>
- scenes: use 7 to 9 scenes. Each scene is one visual moment, lasting about <<SCENE_MIN>> to <<SCENE_MAX>> seconds when spoken. All scene "text" fields joined in order form the full voiceover, so they must flow as connected sentences.
- text: Hindi in Devanagari, 6 to 14 words.
- keyword: 2 to 3 English words describing a generic stock video that a camera can film, such as "smartphone typing", "digital lock", "data network", "credit card payment", "keyboard typing", "server room", "qr code scan" or "mobile notification". Never use police, criminals, hooded hackers, people in distress, identifiable faces, real brands or logos. If no neutral visual fits, use "abstract technology".
- on_screen_text: a short Hindi headline of at most 5 words. Latin acronyms such as OTP or UPI are allowed here. Use "" if not needed.
- highlight_words: 1 or 2 words copied exactly from that scene's "text" (key words).
- presenter_moment: always false for now.
